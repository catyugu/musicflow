# 曲谱同步视频需求

输入为原始 PDF、演奏录音和 MusicXML/MXL。输出为可直接播放的 MP4。命令行支持单例分析、预览、
完整视频和语料批处理。运行环境面向 Windows 原生 CPU。

- `switch` 按演奏顺序裁切和切换 PDF 谱行，完整保留谱面笔画及标记。
- `flow` 用符号谱生成一条连续谱面，将演奏中的音符位置移过固定阅读线。乐谱上的重复段按演奏路线回访。
- 两种模式以原录音为主时钟。记录符号谱、印刷谱和录音间待校勘的差异，并支持人工修订演奏路线、
  PDF 谱行的小节范围和对齐锚点。
- 对语料复用昂贵分析，支持同一案例在两个模式间共享路线与时间映射。报告保留输入指纹、
  分析证据、未确认问题和耗时。

## 验收

| 项目 | 判据 |
| --- | --- |
| PDF | 四例的谱行数与小节绑定匹配基线 |
| 对齐 | 覆盖率至少 90%，音头残差中位数最多 150 ms |
| MIDI 真值 | case1 与 case3 去除整体偏移后的 p50 最多 20 ms，p90 最多 60 ms |
| 视频 | 两模式均提供录音音轨、匹配时长和帧数、抽样谱面完整，`flow` 阅读线固定 |
| 性能 | 1080p/30 fps 下 `switch` 约 7.5–10.2 ms/帧，`flow` 画面合成低于 25 ms/帧 |
